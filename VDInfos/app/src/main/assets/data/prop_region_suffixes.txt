# Region / market suffixes appended to a device identity on some partitions but
# not others. A stock device legitimately carries the same codename with a region
# suffix on one partition (ro.product.product.name = merlin_global) and bare on
# another (ro.product.odm.name = merlin), or dash-joined (Transsion ro.product.
# name = KM6-RU vs KM6-OP). Both are the SAME device, so the per-partition
# "Variants by partition" probe must treat them as one identity, not a divergence.
#
# A trailing "[-_]<suffix>" is stripped from an identity value before the
# cross-partition comparison, but ONLY when the suffix is one of these market
# codes AND the part before it is at least 2 chars - so a real codename is never
# collapsed into a different device (merlin != dandelion stays a divergence).
# Measured on the corpus: strips the merlin/merlin_global and KM6-RU/KM6-OP false
# divergences, 0 cross-device false merges. One code per line, lowercase.
#
