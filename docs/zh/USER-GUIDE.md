# VD Infos 用户指南

VD Infos 是一个**设备方法调试器**。它通过每一种能够读取某个设备值的方法去读取该值，并把这些读数并排
排列，供你比较。本指南涵盖安装应用、运行扫描、阅读结果以及分享报告。它不会替你解读任何具体发现：比较
是你自己要读的，在你自己的设备上。

## 1. VD Infos 是什么

Android 把你设备的大量信息交给你安装的每一个应用。VD Infos 向你展示一个普通应用能读取到什么的示例，
它以一个*方法调试器*的方式来做这件事：对每一条信息，它都通过**每一种能读取该信息的方法**去读取它的
值 - 平台 API、系统属性、原生调用、系统管理器、内容
提供者、文件、系统调用，以及硬件密钥证明（TEE） - 并把它们并排排列，供你比较。它是一面镜头，而不是一
台裁决机器：它把读数呈现出来，把阅读它们这件事留给你。

## 2. 它不是什么

- 它**不是**清理工具、加速器或隐藏工具。它不改变你系统上的任何东西；它只读取与比较。
- 它**不是**一个通过/失败的分数。它向你展示原始读数；它们对你的配置意味着什么，由你来判断，在你的设备
  上。
- 它**不需要**互联网，并且在互联网被屏蔽时也完全可用。

## 3. 要求

- Android 8.0（API 26）或更新版本。
- 启动不需要任何特殊权限。某些读数只有在你授予对应权限（例如使用情况访问）时才变得可用，而某些只在已
  root 的设备上存在；当某个读数不可用时，应用只会显示它当时不可用。

## 4. 该安装哪个 APK

每个发行版都发布**两个 APK**：

- **SDK_35** - 面向严格的现代沙箱。这是该用的那个。
- **SDK_27** - 面向更旧的 API 级别。它仅对并排比较有用；大多数人并不需要它。

两者都能安装在 Android 8.0 及更新版本上。请从
[Releases](https://github.com/VD171/VD-Infos/releases) 页面下载它们。

## 5. 安装与首次运行

1. 从 Releases 下载 **SDK_35** APK 并安装它（你可能需要允许从浏览器或文件管理器安装）。
2. 打开应用。它会直接进入扫描界面；没有账户、没有登录、也没有设置。
3. 可选地授予应用询问的某个权限（例如使用情况访问），以解锁依赖它的那些读数。这完全是可选的。

## 6. 运行扫描

点击扫描操作。应用会把它的探针并行地铺开，并在结果到达时把它们流式送入列表，带有一个实时进度指示器。
一次扫描会自行完成；它只在应用打开时读取，不在后台保留任何运行中的东西，并在被闲置时自行关闭。

要再次运行，就再扫描一次：每次扫描都会替换上一次的结果。

## 7. 阅读结果

每一项都是一张卡片，把来自每一面镜头的读数并排排列（Java SDK 方法、原生方法、shell 等等）。卡片的
颜色让你一眼就能看出这些读数彼此之间的关系：

- **匹配** - 每一面镜头都一致。各方法返回了相同的值。
- **分歧** - 这些镜头不一致。某个方法返回了与其他方法不同的东西。
- **信息** - 为参考而显示的读数，不参与投票。
- **单一 / 不可用** - 只有一面镜头能读取它，或没有任何一面能读取。

卡片始终显示读数的完整矩阵，因此你能确切看到哪面镜头说了什么。折叠的卡片显示它的第一个读数；展开它
即可看到全部。

应用替你发声到此为止。**某个给定的分歧在你的设备上意味着什么、该如何处理，是你自己要去调查的** - 这
正是调试器的全部要点：它把证据摆在你面前，让你去读。使用搜索框按属性或值过滤，并使用过滤芯片来收窄
列表。

## 8. 导出你的报告

分享和保存操作把**整个结果**交给你，而不只是屏幕上的内容：

- **分享 / 另存为 JSON** - 完整的报告，机器可读形式，与应用内部所持有的是同一份数据。这是用来保存或
  喂给工具的格式。
- **以文本分享** - 一份关于各项分歧的紧凑、人类可读的摘要。

承载身份的值（序列号、IMEI、MAC 地址、广告 ID 之类）在**导出的报告中被遮蔽**，这样你粘贴到公共帖子
里的报告就不会泄露你自己的标识符；裁决与结构被保留。只有你（或 root）才能读取的设备上副本保留真实值。

## 9. 面向 AI 代理

VD Infos 的构建是为了被工具读取，而不仅仅是被人读取。每次扫描都会把它的完整报告写入应用的私有存储，
而导出就是同一份机器可读的 JSON。在设备上运行的 AI 编码助手或分析脚本可以用一条命令读取整个结果，而
无需解析截图。参见专门的 [AI 代理指南](AI-AGENTS.md) 和 [导出格式](EXPORT-FORMAT.md) 参考。

## 10. 语言与主题

应用会在存在翻译的地方跟随你的系统语言，你也可以手动选择一种。它使用带动态取色的 Material 3，并跟随
你的浅色/深色设置。

## 11. 隐私一览

一切都在设备上运行。没有任何读数被发送到任何地方，报告只有在你明确分享或保存它时才会离开设备。每次
扫描都把它的完整报告保存在应用的私有存储（`files/last_snapshot.json`）中，以便工具能读取它；只有应用
本身或 root 能读取该文件，下一次扫描会覆盖它，并且它永远不会离开设备。完整声明参见
[隐私](PRIVACY.md)。

## 12. 常见问题

**它会改变我设备上的任何东西吗？** 不会。它只读取与比较。

**它需要 root 吗？** 不需要。应用无需 root 即可运行。有一小撮读数只在已 root 的设备上存在，而私有报告
文件只能由 root 或应用本身读回；其余一切在未 root 时都能工作。

**它需要互联网吗？** 不需要。它完全离线工作；如果你愿意，可以屏蔽它的网络访问。

**我该用哪个 APK？** SDK_35。SDK_27 构建只为比较而存在。

**为什么有些项显示不可用？** 因为该方法在你的设备上无法读取那个值 - 缺少某个权限、某条沙箱规则，或是
不存在的硬件。这本身就是比较的一部分。

**我在哪里报告问题或建议一个检测目标？** 参见
[贡献](CONTRIBUTING.md)；大多数检测列表是纯文本，不需要代码。
