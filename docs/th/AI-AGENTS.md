# VD Infos สำหรับเอเจนต์ AI

VD Infos **สร้างขึ้นเพื่อให้เครื่องอ่าน ไม่ใช่เฉพาะคนเท่านั้น** เครื่องมือดีบักเมธอดของอุปกรณ์ผลิตหลักฐานเชิงโครงสร้างจำนวนมาก -
ทุกค่า อ่านผ่านทุกเมธอด จัดเรียงไว้เพื่อเปรียบเทียบ - และหลักฐานนั้นมีประโยชน์ต่อเอเจนต์มากกว่าในฐานะข้อมูลมากกว่าในฐานะภาพหน้าจอ
ดังนั้นผลลัพธ์ทั้งหมดจึงพร้อมใช้งานในรูปเอกสารเดียวที่เครื่องอ่านได้ และแอปถูกออกแบบรอบสิ่งนั้นตั้งแต่พื้นฐาน

หากคุณเป็นผู้ช่วยเขียนโค้ด AI, เครื่องมือ LLM, สคริปต์วิเคราะห์ หรือระบบอัตโนมัติใด ๆ ที่เข้าถึงอุปกรณ์ผ่านเชลล์ หน้านี้มีไว้สำหรับคุณ

## เหตุใดมันจึงเป็นมิตรกับเอเจนต์

- **เอกสารเดียว ไม่ใช่หน้าจอ** การสแกนทั้งหมด - ทุกโพรบ ทุกเลนส์ ทุกคำตัดสิน - เป็นออบเจกต์ JSON เดียว ไม่มี OCR
  ไม่มีการขูดหน้าจอ ไม่มีการแตะผ่านการ์ดที่ยุบอยู่
- **ข้อมูลเดียวกับที่ UI มี** ไฟล์นี้ไม่ใช่บทสรุป มันคือสิ่งที่แอปเก็บไว้ภายในอย่างแน่นอน: หน้าจอแสดงการอ่านค่าแรกของรายการที่ยุบอยู่
  ไฟล์มีทั้งหมด
- **รูปทรงที่กำหนดได้แน่นอน** โครงสร้างมีความเสถียรและมีเอกสารกำกับ (ดู [EXPORT-FORMAT](EXPORT-FORMAT.md))
  ดังนั้นพาร์เซอร์ที่เขียนครั้งเดียวจะยังคงทำงานต่อไป
- **ไม่มีเครือข่าย ไม่มีบัญชี ไม่มีสถานะที่ต้องจัดการ** แอปอ่านบนอุปกรณ์และเขียนไฟล์ เอเจนต์ของคุณอ่านไฟล์ นั่นคือสัญญาทั้งหมด
- **ออฟไลน์โดยการออกแบบ** มันไม่ต้องการอินเทอร์เน็ต ดังนั้นมันจึงทำงานเหมือนเดิมภายในสภาพแวดล้อมที่ถูกล็อกดาวน์หรือตัดขาดจากเครือข่าย
  ซึ่งเอเจนต์อาจกำลังทำงานอยู่

## การอ่านด้วยคำสั่งเดียว

การสแกนทุกครั้งจะเขียนรายงานฉบับสมบูรณ์ลงในที่เก็บข้อมูลส่วนตัวของแอป หลังจากการสแกนทำงานแล้ว เอเจนต์จะอ่านผลลัพธ์ฉบับสมบูรณ์
ด้วยคำสั่งเดียว:

```sh
su -c cat /data/data/ru.vd171.vdinfos/files/last_snapshot.json
```

- **สิ่งที่มันมี:** ทุกโพรบพร้อมคำตัดสินของมันและค่าจากทุกเลนส์ ใน JSON แบบเดียวกับปุ่มส่งออก
- **เมื่อใดที่มันอัปเดต:** เมื่อสิ้นสุดการสแกนทุกครั้ง เรียกใช้การสแกนก่อน ไฟล์จะเก็บการสแกนล่าสุดไว้เสมอ
- **ข้อกำหนด:** root เพราะไฟล์อยู่ในที่เก็บข้อมูลส่วนตัวของแอป หากไม่มี root ให้ใช้การกระทำ **แชร์ / บันทึกเป็น JSON**
  ในแอปแทน แล้วอ่านไฟล์ที่เอเจนต์ได้รับมอบ

## โฟลว์ของเอเจนต์ทั่วไป

1. ตรวจสอบให้แน่ใจว่าติดตั้งแอปแล้ว (APK **SDK_35** จาก [Releases](https://github.com/VD171/VD-Infos/releases))
2. ทริกเกอร์การสแกน - คนแตะสแกน หรือระบบอัตโนมัติเปิดหน้าจอสแกนของแอป - และรอให้มันเสร็จสิ้น
3. อ่าน `files/last_snapshot.json` ด้วยคำสั่งด้านบน
4. แยกวิเคราะห์มันด้วย[รูปแบบการส่งออก](EXPORT-FORMAT.md) เป็นสคีมาของคุณ: วนซ้ำโพรบต่าง ๆ อ่าน `verdict` ของแต่ละตัว
   และจัดเรียง `values` แบบต่อเลนส์
5. ดำเนินการกับผลลัพธ์เชิงโครงสร้างในเวิร์กโฟลว์ของคุณเอง

เอเจนต์เป็นผู้ตัดสินใจว่าการอ่านค่าหมายถึงอะไรสำหรับงานที่กำลังทำ VD Infos จัดหาหลักฐาน อย่างสะอาดและครบถ้วน

## สิ่งที่เอเจนต์ได้รับ และสิ่งที่มันไม่ได้รับ

- รายงานพก **ทุกการอ่านค่าและทุกคำตัดสิน** ดังนั้นเอเจนต์จึงมีภาพรวมทั้งหมดที่แอปสร้างขึ้น
- ค่าที่บ่งบอกตัวตน (หมายเลขซีเรียล, IMEI, ที่อยู่ MAC, รหัสโฆษณา และอื่น ๆ ทำนองนั้น) จะถูก **ปิดบังในรายงานที่แชร์/ส่งออก**
  ดังนั้นรายงานที่ส่งต่อกันไปมาจึงปราศจากตัวระบุส่วนบุคคลในขณะที่ยังคงคำตัดสินและโครงสร้างไว้ **สำเนาบนอุปกรณ์**
  `last_snapshot.json` ที่อ่านได้โดยแอปหรือ root เท่านั้น จะเก็บค่าจริงไว้สำหรับเอเจนต์ในเครื่องที่ต้องการมัน

## เอกสาร เขียนไว้เพื่อให้แยกวิเคราะห์ได้

วิกินี้มีโครงสร้างสำหรับการอ่านด้วยเครื่องมากพอ ๆ กับสำหรับคน: ส่วนที่สั้น หัวเรื่องที่เสถียร ชื่อฟิลด์ที่ชัดเจน
และหน้า[รูปแบบการส่งออก](EXPORT-FORMAT.md) ที่เฉพาะเจาะจงซึ่งเอเจนต์สามารถปฏิบัติต่อเป็นสคีมาได้ หากคุณกำลังสร้างเครื่องมือบน VD Infos
ให้เริ่มที่นั่น
