# นโยบายความปลอดภัย

VD Infos เป็นเครื่องมือด้านความเป็นส่วนตัวที่อ่านสถานะอุปกรณ์ที่ละเอียดอ่อน ดังนั้นรายงานด้านความปลอดภัยจึงได้รับการพิจารณาอย่างจริงจัง

## การรายงานช่องโหว่

โปรดรายงานปัญหาด้านความปลอดภัย **แบบส่วนตัว** ไม่ใช่ในประเด็นสาธารณะ:

- ส่งอีเมลไปที่ **vd.priv8@pm.me**
- อธิบายปัญหา เวอร์ชันที่ได้รับผลกระทบ และวิธีการทำซ้ำมัน
- หากเกี่ยวข้องกับการเปิดเผยข้อมูล ให้อธิบายประเภทของปัญหา คุณไม่จำเป็นต้องแนบ exploit ที่ใช้งานได้

คุณจะได้รับการตอบกลับโดยเร็วที่สุด โปรดให้ช่วงเวลาที่สมเหตุสมผลในการแก้ไขปัญหาก่อนการเปิดเผยสู่สาธารณะใด ๆ

## สิ่งใดที่นับเป็นปัญหาด้านความปลอดภัย

เนื่องจากสิ่งที่ VD Infos สัญญาไว้ สิ่งเหล่านี้จึงสำคัญเป็นพิเศษ:

- สิ่งใดก็ตามที่จะทำให้แอปเข้าถึงเครือข่าย หรือส่งการอ่านค่าใด ๆ ออกจากอุปกรณ์
- สิ่งใดก็ตามที่จะทำให้ค่าที่บ่งบอกตัวตนรั่วไหลไปยัง **การส่งออก** ที่แชร์หรือบันทึก (หมายเลขซีเรียล, IMEI, ที่อยู่ MAC,
  รหัสโฆษณา และอื่น ๆ ทำนองนั้น) แม้จะมีการปิดบัง
- สิ่งใดก็ตามที่ให้แอปอื่นอ่านไฟล์รายงานส่วนตัวซึ่งควรอ่านได้โดยตัวแอปเองหรือ root เท่านั้น

## สิ่งใดที่ไม่ใช่ปัญหาด้านความปลอดภัย

- การอ่านค่าที่ดู "ผิด" แต่เป็นค่าที่ซื่อสัตย์ที่เมธอดส่งคืน VD Infos รายงานสิ่งที่แต่ละเมธอดบอก การอ่านการเปรียบเทียบเป็นของคุณที่จะทำ
  ดู[คู่มือผู้ใช้](USER-GUIDE.md)
- การอ่านค่าที่ทำเครื่องหมายว่าไม่พร้อมใช้งาน นั่นหมายความว่าเมธอดหนึ่งไม่สามารถอ่านค่านั้นบนอุปกรณ์ของคุณได้ ซึ่งเองก็เป็นส่วนหนึ่งของการเปรียบเทียบ

## เวอร์ชันที่รองรับ

รองรับเฉพาะเวอร์ชันล่าสุดที่เผยแพร่เท่านั้น โปรดทำซ้ำบนบิลด์ล่าสุดก่อนรายงาน
