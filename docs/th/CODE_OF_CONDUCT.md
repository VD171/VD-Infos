# จรรยาบรรณ

## คำมั่นสัญญาของเรา

ในฐานะสมาชิก ผู้มีส่วนร่วม และผู้ดูแล เราขอให้คำมั่นว่าจะทำให้การมีส่วนร่วมในชุมชน VD Infos เป็นประสบการณ์ที่ปราศจากการคุกคาม
สำหรับทุกคน โดยไม่คำนึงถึงอายุ ขนาดร่างกาย ความพิการที่มองเห็นได้หรือมองไม่เห็น ชาติพันธุ์ ลักษณะทางเพศ อัตลักษณ์และการแสดงออกทางเพศ
ระดับประสบการณ์ การศึกษา สถานะทางเศรษฐกิจและสังคม สัญชาติ รูปลักษณ์ส่วนบุคคล เชื้อชาติ ศาสนา หรืออัตลักษณ์และรสนิยมทางเพศ

## มาตรฐานของเรา

ตัวอย่างของพฤติกรรมที่ส่งเสริมสภาพแวดล้อมเชิงบวก:

- การเคารพในความคิดเห็น มุมมอง และประสบการณ์ที่แตกต่าง
- การให้และยอมรับคำติชมที่สร้างสรรค์อย่างสุภาพ
- การมุ่งเน้นไปที่สิ่งที่ดีที่สุดสำหรับชุมชน
- การแสดงความเห็นอกเห็นใจต่อผู้อื่น

ตัวอย่างของพฤติกรรมที่ยอมรับไม่ได้:

- การก่อกวน การดูหมิ่นหรือความคิดเห็นที่เหยียดหยาม และการโจมตีส่วนบุคคลหรือทางการเมือง
- การคุกคามในที่สาธารณะหรือส่วนตัว
- การเผยแพร่ข้อมูลส่วนตัวของผู้อื่นโดยไม่ได้รับอนุญาตอย่างชัดแจ้ง
- พฤติกรรมอื่นที่อาจถือได้อย่างสมเหตุสมผลว่าไม่เหมาะสมในสภาพแวดล้อมแบบมืออาชีพ
