# คู่มือผู้ใช้ VD Infos

VD Infos เป็น **เครื่องมือดีบักเมธอดของอุปกรณ์** มันอ่านทุกค่าของอุปกรณ์ผ่านทุกเมธอดที่สามารถอ่านค่านั้นได้
และจัดเรียงการอ่านค่าเคียงข้างกันเพื่อให้คุณเปรียบเทียบได้ คู่มือนี้ครอบคลุมการติดตั้งแอป การเรียกใช้การสแกน
การอ่านผลลัพธ์ และการแชร์รายงาน มันไม่ตีความผลลัพธ์เฉพาะใด ๆ ให้คุณ การเปรียบเทียบเป็นของคุณที่จะอ่านเอง
บนอุปกรณ์ของคุณเอง

## 1. VD Infos คืออะไร

Android ส่งข้อมูลของอุปกรณ์คุณจำนวนมากให้กับทุกแอปที่คุณติดตั้ง VD Infos แสดงตัวอย่างของสิ่งที่แอปทั่วไปสามารถอ่านได้
และทำเช่นนั้นในฐานะ *เครื่องมือดีบักเมธอด*: สำหรับข้อมูลแต่ละชิ้น มันอ่านค่าผ่าน **ทุกเมธอดที่สามารถอ่านค่านั้นได้** -
API แพลตฟอร์ม, พร็อพเพอร์ตี้ของระบบ, การเรียกเนทีฟ, ตัวจัดการระบบ, content providers, ไฟล์,
syscalls และการพิสูจน์คีย์ด้วยฮาร์ดแวร์ (TEE) - และจัดเรียงให้คุณเปรียบเทียบได้ มันคือเลนส์ ไม่ใช่เครื่องตัดสิน:
มันนำการอ่านค่าขึ้นมาแสดงและปล่อยให้การอ่านค่านั้นเป็นของคุณ

## 2. สิ่งที่มันไม่ใช่

- มัน**ไม่ใช่**ตัวล้างข้อมูล ตัวเร่งความเร็ว หรือเครื่องมือซ่อน มันไม่เปลี่ยนแปลงอะไรบนระบบของคุณ มันเพียงอ่านและเปรียบเทียบ
- มัน**ไม่ใช่**คะแนนผ่าน/ไม่ผ่าน มันแสดงการอ่านค่าดิบให้คุณ ส่วนความหมายของมันต่อการตั้งค่าของคุณเป็นของคุณที่จะตัดสิน
  บนอุปกรณ์ของคุณ
- มัน**ไม่**ต้องการอินเทอร์เน็ต และทำงานได้อย่างสมบูรณ์เมื่อบล็อกอินเทอร์เน็ต

## 3. ข้อกำหนด

- Android 8.0 (API 26) หรือใหม่กว่า
- ไม่ต้องการสิทธิ์พิเศษใด ๆ ในการเริ่มต้น การอ่านค่าบางอย่างจะใช้งานได้ก็ต่อเมื่อคุณให้สิทธิ์ที่ตรงกันเท่านั้น
  (ตัวอย่างเช่น การเข้าถึงการใช้งาน) และบางอย่างมีอยู่เฉพาะบนอุปกรณ์ที่รูทแล้วเท่านั้น ในกรณีที่การอ่านค่าไม่พร้อมใช้งาน
  แอปจะแสดงเพียงว่ามันไม่พร้อมใช้งาน

## 4. APK ที่ควรติดตั้ง

แต่ละรีลีสเผยแพร่ **APK สองตัว**:

- **SDK_35** - มุ่งเป้าไปที่แซนด์บ็อกซ์สมัยใหม่ที่เข้มงวด นี่คือตัวที่ควรใช้
- **SDK_27** - มุ่งเป้าไปที่ API ระดับเก่ากว่า มีประโยชน์เฉพาะสำหรับการเปรียบเทียบ
  เคียงข้างกันเท่านั้น คนส่วนใหญ่ไม่จำเป็นต้องใช้มัน

ทั้งสองตัวติดตั้งได้บน Android 8.0 และใหม่กว่า ดาวน์โหลดได้จากหน้า
[Releases](https://github.com/VD171/VD-Infos/releases)

## 5. การติดตั้งและการเรียกใช้ครั้งแรก

1. ดาวน์โหลด APK **SDK_35** จาก Releases และติดตั้งมัน (คุณอาจต้องอนุญาตการติดตั้งจากเบราว์เซอร์หรือตัวจัดการไฟล์ของคุณ)
2. เปิดแอป มันจะเปิดตรงไปยังหน้าจอสแกน ไม่มีบัญชี ไม่มีการลงชื่อเข้าใช้ และไม่มีการตั้งค่า
3. ให้สิทธิ์ที่แอปร้องขอตามต้องการ (เช่น การเข้าถึงการใช้งาน) เพื่อปลดล็อกการอ่านค่าที่ขึ้นอยู่กับมัน นี่เป็นเรื่องเลือกได้ทั้งหมด

## 6. การเรียกใช้การสแกน

แตะที่การกระทำสแกน แอปจะกระจายโพรบออกไปแบบขนานและสตรีมผลลัพธ์เข้าสู่รายการเมื่อผลลัพธ์มาถึง
พร้อมตัวบ่งชี้ความคืบหน้าแบบสด การสแกนจะเสร็จสิ้นด้วยตัวเอง มันอ่านค่าเฉพาะขณะที่แอปเปิดอยู่
ไม่คงอะไรทำงานไว้เบื้องหลัง และปิดตัวเองเมื่อถูกทิ้งไว้ว่าง

หากต้องการเรียกใช้อีกครั้ง ให้สแกนอีกครั้ง การสแกนแต่ละครั้งจะแทนที่ผลลัพธ์ก่อนหน้า

## 7. การอ่านผลลัพธ์

แต่ละรายการคือการ์ดที่จัดเรียงการอ่านค่าจากทุกเลนส์ (เมธอด Java SDK, เมธอดเนทีฟ, เชลล์ และอื่น ๆ)
สีของการ์ดบอกคุณได้ในพริบตาว่าการอ่านค่าเหล่านั้นสัมพันธ์กันอย่างไร:

- **ตรงกัน** - ทุกเลนส์เห็นตรงกัน เมธอดต่าง ๆ ส่งคืนค่าเดียวกัน
- **แตกต่าง** - เลนส์ไม่เห็นตรงกัน เมธอดหนึ่งส่งคืนบางอย่างที่ต่างจากเมธอดอื่น
- **ข้อมูล** - การอ่านค่าที่แสดงไว้เพื่ออ้างอิง ไม่ได้นำมาลงคะแนน
- **เดี่ยว / ไม่พร้อมใช้งาน** - มีเพียงเลนส์เดียวที่อ่านได้ หรือไม่มีเลนส์ใดอ่านได้

การ์ดจะแสดงเมทริกซ์การอ่านค่าแบบเต็มเสมอ เพื่อให้คุณเห็นได้ชัดเจนว่าเลนส์ใดบอกอะไร การ์ดที่ยุบอยู่จะแสดงการอ่านค่าแรกของมัน
ขยายมันเพื่อดูทั้งหมด

นั่นคือขอบเขตที่แอปพูดแทนคุณ **ความหมายของความแตกต่างหนึ่ง ๆ บนอุปกรณ์ของคุณ และสิ่งที่ควรทำกับมัน เป็นของคุณที่จะสืบค้นเอง** -
นั่นคือประเด็นทั้งหมดของเครื่องมือดีบัก: มันวางหลักฐานไว้ตรงหน้าคุณและปล่อยให้คุณอ่านมัน ใช้ช่องค้นหาเพื่อกรองตามคุณสมบัติหรือค่า
และใช้ชิปตัวกรองเพื่อจำกัดรายการให้แคบลง

## 8. การส่งออกรายงานของคุณ

การกระทำแชร์และบันทึกจะมอบ **ผลลัพธ์ทั้งหมด** ให้คุณ ไม่ใช่เฉพาะสิ่งที่อยู่บนหน้าจอ:

- **แชร์ / บันทึกเป็น JSON** - รายงานฉบับสมบูรณ์ในรูปแบบที่เครื่องอ่านได้ ซึ่งเป็นข้อมูลเดียวกับที่แอปเก็บไว้ภายใน
  นี่คือรูปแบบที่ควรเก็บไว้หรือป้อนให้กับเครื่องมือ
- **แชร์เป็นข้อความ** - สรุปที่มนุษย์อ่านได้อย่างกระชับของความแตกต่างต่าง ๆ

ค่าที่บ่งบอกตัวตน (หมายเลขซีเรียล, IMEI, ที่อยู่ MAC, รหัสโฆษณา และอื่น ๆ ทำนองนั้น) จะถูก **ปิดบังในรายงานที่ส่งออก**
เพื่อให้รายงานที่คุณวางลงในเธรดสาธารณะไม่รั่วไหลตัวระบุของคุณเอง คำตัดสินและโครงสร้างจะถูกเก็บรักษาไว้
สำเนาบนอุปกรณ์ที่มีเพียงคุณ (หรือ root) เท่านั้นที่อ่านได้จะเก็บค่าจริงไว้

## 9. สำหรับเอเจนต์ AI

VD Infos สร้างขึ้นเพื่อให้เครื่องมืออ่าน ไม่ใช่เฉพาะคนเท่านั้น การสแกนทุกครั้งจะเขียนรายงานฉบับสมบูรณ์ลงในที่เก็บข้อมูลส่วนตัวของแอป
และการส่งออกคือ JSON ที่เครื่องอ่านได้แบบเดียวกัน ผู้ช่วยเขียนโค้ด AI หรือสคริปต์วิเคราะห์ที่ทำงานบนอุปกรณ์สามารถอ่านผลลัพธ์ทั้งหมด
ด้วยคำสั่งเดียวแทนที่จะแยกวิเคราะห์ภาพหน้าจอ ดู[คู่มือเอเจนต์ AI](AI-AGENTS.md) ที่เฉพาะเจาะจงและข้อมูลอ้างอิง[รูปแบบการส่งออก](EXPORT-FORMAT.md)

## 10. ภาษาและธีม

แอปจะตามภาษาระบบของคุณในที่ที่มีการแปลอยู่ และคุณสามารถเลือกเองด้วยตนเองได้ มันใช้ Material 3 ด้วยสีแบบไดนามิก
และตามการตั้งค่าสว่าง/มืดของคุณ

## 11. ความเป็นส่วนตัวโดยสังเขป

ทุกอย่างทำงานบนอุปกรณ์ ไม่มีการอ่านค่าใดถูกส่งไปที่ใด และรายงานจะออกจากอุปกรณ์ก็ต่อเมื่อคุณแชร์หรือบันทึกมันอย่างชัดแจ้งเท่านั้น
การสแกนแต่ละครั้งจะเก็บรายงานฉบับสมบูรณ์ไว้ในที่เก็บข้อมูลส่วนตัวของแอป (`files/last_snapshot.json`) เพื่อให้เครื่องมืออ่านได้
มีเพียงตัวแอปเองหรือ root เท่านั้นที่อ่านไฟล์นั้นได้ การสแกนครั้งถัดไปจะเขียนทับมัน และมันไม่เคยออกจากอุปกรณ์
ดู[ความเป็นส่วนตัว](PRIVACY.md) สำหรับคำแถลงฉบับเต็ม

## 12. คำถามที่พบบ่อย

**มันเปลี่ยนแปลงอะไรบนอุปกรณ์ของฉันหรือไม่?** ไม่ มันเพียงอ่านและเปรียบเทียบ

**มันต้องการ root หรือไม่?** ไม่ แอปทำงานได้โดยไม่ต้องรูท การอ่านค่าจำนวนหนึ่งมีอยู่เฉพาะบนอุปกรณ์ที่รูทแล้วเท่านั้น
และไฟล์รายงานส่วนตัวสามารถอ่านกลับได้โดย root หรือตัวแอปเองเท่านั้น ส่วนที่เหลือทั้งหมดทำงานได้โดยไม่ต้องรูท

**มันต้องการอินเทอร์เน็ตหรือไม่?** ไม่ มันทำงานแบบออฟไลน์ได้อย่างสมบูรณ์ บล็อกการเข้าถึงเครือข่ายของมันได้หากคุณต้องการ

**ฉันควรใช้ APK ตัวใด?** SDK_35 บิลด์ SDK_27 มีอยู่เพื่อการเปรียบเทียบเท่านั้น

**เหตุใดบางรายการจึงบอกว่าไม่พร้อมใช้งาน?** เพราะเมธอดนั้นไม่สามารถอ่านค่านั้นบนอุปกรณ์ของคุณได้ -
สิทธิ์ที่ขาดหายไป กฎของแซนด์บ็อกซ์ หรือฮาร์ดแวร์ที่ไม่มีอยู่ นั่นเองก็เป็นส่วนหนึ่งของการเปรียบเทียบ

**ฉันจะรายงานปัญหาหรือเสนอเป้าหมายการตรวจจับได้ที่ไหน?** ดู[การมีส่วนร่วม](CONTRIBUTING.md)
รายการตรวจจับส่วนใหญ่เป็นข้อความธรรมดาและไม่ต้องการโค้ด
