# สถาปัตยกรรม

นี่คือแผนที่ระดับสูงของวิธีการประกอบ VD Infos ขึ้น มันอธิบายรูปทรงของแอป ไม่ใช่แคตาล็อกของสิ่งที่มันอ่าน:
ประเด็นของเครื่องมือดีบักเมธอดคือการวางทุกการอ่านค่าไว้ตรงหน้าคุณ และการอ่านมันเป็นของคุณที่จะทำบนอุปกรณ์ของคุณเอง

## เป้าหมายการออกแบบ

- **หนึ่งค่า ทุกเมธอด** สำหรับข้อมูลแต่ละชิ้น ให้อ่านมันผ่านทุกเมธอดที่สามารถอ่านได้และจัดเรียงการอ่านค่า
  เครื่องมือดีบักนำหลักฐานขึ้นมาแสดง มันไม่ตัดสิน
- **บนอุปกรณ์และเงียบ** ไม่มีเครือข่าย ไม่มีบัญชี ไม่มีงานเบื้องหลัง แอปทำงานเฉพาะขณะที่มันเปิดอยู่
- **เครื่องอ่านได้** ผลลัพธ์ทั้งหมดเป็นเอกสารเดียวที่เครื่องอ่านได้ ดังนั้นเครื่องมือจึงได้ภาพรวมเดียวกับที่คนได้
  ดู [เอเจนต์ AI](AI-AGENTS.md)
- **เล็กในที่ที่สำคัญ** ส่วนที่ต้องหลอกได้ยากถูกเก็บให้เล็กจิ๋วโดยเจตนา

## เลนส์ต่าง ๆ

*เลนส์* คือวิธีหนึ่งในการอ่านค่า ค่าเดียวกันถูกอ่านผ่านหลายวิธีเพื่อให้สามารถเปรียบเทียบกันได้:

| เลนส์ | มันคืออะไร |
|---|---|
| **Java / SDK** | API ของแพลตฟอร์มที่แอปทั่วไปเรียกใช้ |
| **Native / JNI** | ค่าเดียวกันที่อ่านจากโค้ดเนทีฟ |
| **Shell via JVM** | คำสั่งเชลล์ที่ JVM สร้างขึ้น |
| **Shell via JNI** | คำสั่งเดียวกันที่สร้างจากโค้ดเนทีฟ จุดสังเกตที่ต่างออกไป |
| **TEE / Attestation** | การพิสูจน์คีย์ที่ได้รับการสนับสนุนด้วยฮาร์ดแวร์ ในที่ที่มันใช้ได้ |

การจัดเรียงเลนส์คือแนวคิดทั้งหมด: เมื่อพวกมันไม่เห็นตรงกัน มีบางสิ่งระหว่างแอปกับค่าที่กำลังตอบแตกต่างกันต่อผู้เรียกที่ต่างกัน
สิ่งนั้นหมายถึงอะไรสำหรับค่าหนึ่ง ๆ บนอุปกรณ์หนึ่ง ๆ เป็นของคุณที่จะอ่าน

## การสแกนทำงานอย่างไร

```
core/model      immutable domain: Lens, Category, Verdict, ProbeSpec, ProbeResult
probe/          the probes and the bridges they use (JNI, reflection, data lists)
engine/         ProbeEngine: parallel fan-out, streams results as they land
data/           SnapshotStore (persist the report), Exporter (share as JSON / text)
ui/             Jetpack Compose, Material 3, dynamic colour, live progress
cpp/            native_probes.cpp: the native lens, dependency-free
```

- **การทำงานแบบขนาน** โพรบกระจายออกไปบนดิสแพตเชอร์ที่มีจำนวนสิทธิ์จำกัด ผลลัพธ์สตรีมเข้าสู่ UI เมื่อเสร็จสิ้น
  พร้อมตัวบ่งชี้ความคืบหน้าแบบสด
- **ไม่มีอะไรทำงานเบื้องหลัง** ไม่มีบริการและไม่มีการสแกนตามกำหนดเวลา แอปอ่านเฉพาะขณะที่เปิดอยู่และปิดตัวเองเมื่อถูกทิ้งไว้ว่าง
- **เลเยอร์เนทีฟ** `.so` ขนาดเล็กหนึ่งตัว ผูกด้วยชื่อผ่าน `RegisterNatives` เก็บให้เล็กจิ๋วโดยเจตนาเพราะมันเป็นส่วนที่ต้องหลอกได้ยาก

## รายงาน

การสแกนทุกครั้งผลิต `Snapshot`: เวลาที่ทำการสแกน เวอร์ชันแอป และรายการผลลัพธ์ หนึ่งรายการต่อโพรบ
แต่ละตัวมีการอ่านค่าจากทุกเลนส์และคำตัดสินว่าพวกมันสัมพันธ์กันอย่างไร แอปบันทึกสิ่งนี้ลงในที่เก็บข้อมูลส่วนตัวหลังการสแกนแต่ละครั้ง
และสามารถส่งออกข้อมูลเดียวกันได้ โครงสร้างถูกจัดทำเป็นเอกสารเป็น[รูปแบบการส่งออก](EXPORT-FORMAT.md)

## การขยายมัน

สิ่งที่แอปค้นหาส่วนใหญ่อยู่ในรูป **รายการข้อความธรรมดา** ภายใต้ `assets/data/` ไม่ใช่ในรูปโค้ด
การเพิ่มหรือลบเป้าหมายคือการแก้ไขหนึ่งบรรทัด ดู[การมีส่วนร่วม](CONTRIBUTING.md)

## สิ่งที่ VD Infos ไม่เคยทำ

- มันไม่เคยเปลี่ยนแปลงอะไรบนระบบของคุณ มันเพียงอ่านและเปรียบเทียบ
- มันไม่เคยติดต่อกับเครือข่าย มันทำงานแบบออฟไลน์ได้อย่างสมบูรณ์
- มันไม่เคยทำงานเบื้องหลัง ไม่เคยกำหนดเวลาการสแกน หรือคงบริการให้มีชีวิตอยู่
- มันไม่เคยส่งการอ่านค่าไปที่ใด รายงานจะออกจากอุปกรณ์ก็ต่อเมื่อคุณแชร์หรือบันทึกมัน โดยค่าที่บ่งบอกตัวตนถูกปิดบัง
