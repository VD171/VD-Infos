# การมีส่วนร่วม

ขอบคุณสำหรับความสนใจใน VD Infos การมีส่วนร่วมเป็นที่ยินดี: รายการตรวจจับ การแปล รายงานข้อบกพร่อง เอกสาร และโค้ด
การมีส่วนร่วมส่วนใหญ่ไม่ต้องใช้ Kotlin

## การมีส่วนร่วมที่ง่ายที่สุด: รายการต่าง ๆ

สิ่งที่แอปค้นหาส่วนใหญ่อยู่ในรูป **รายการข้อความธรรมดา** ภายใต้ `VDInfos/app/src/main/assets/data/` ไม่ใช่ในรูปโค้ด
การเพิ่มหรือลบเป้าหมายคือการแก้ไขหนึ่งบรรทัดและเปิด pull request:

- `*_apps.txt` - หนึ่งชื่อแพ็กเกจต่อบรรทัด
- `props.txt` - แคตาล็อกคุณสมบัติระบบ `CATEGORY<tab>key`
- `spoof_keys.txt` - เมทริกซ์การตั้งค่า `key:TYPE`
- `known_certs.txt` - แคตาล็อกใบรับรองการลงนาม `SHA-256<tab>owner` (แฮชฉบับเต็ม นำมาจาก APK จริงด้วย
  `apksigner verify --print-certs`)
- ไฟล์ `.txt` อื่น ๆ - หนึ่งรายการต่อบรรทัด (เศษชื่อเคอร์เนลโมดูล ชื่อไฟล์ และอื่น ๆ)

`#` เริ่มต้นความคิดเห็นและบรรทัดว่างจะถูกละเว้น บางไฟล์อัดฟิลด์ที่คั่นด้วยช่องว่างหรือแท็บไม่กี่ฟิลด์ต่อบรรทัด
หรือมีเครื่องหมายเสริม ให้คงรูปทรงของบรรทัดที่มีอยู่แล้วในไฟล์

## กฎพื้นฐาน

- **VD Infos อ่านความจริงและไม่เคยปลอมแปลงอะไร** มันรายงานสิ่งที่แต่ละเมธอดส่งคืน อย่างแม่นยำ อย่าปรับการอ่านค่าให้ดูดีขึ้น
  และอย่าเพิ่มสิ่งใดที่จะเปลี่ยนค่าแทนที่จะอ่านมัน
- **ความเป็นส่วนตัวเป็นสิ่งสัมบูรณ์** ทุกอย่างทำงานบนอุปกรณ์ อย่าเพิ่มการเรียกเครือข่าย หรือสิ่งใดที่ส่งการอ่านค่าออกจากอุปกรณ์
- **การส่งออกยังคงถูกปิดบัง** ค่าที่บ่งบอกตัวตนจะถูกปิดบังในรายงานที่แชร์ รักษาไว้เช่นนั้น

## การแปล

การแปลเป็นการมีส่วนร่วมที่มีค่า readme แปลต่อภาษา (`README.<lang>.md`) สตริงของแอปต่อภาษา และเอกสารนี้ภายใต้ `docs/<lang>/`
รักษาคำศัพท์ให้สอดคล้องกันภายในภาษาหนึ่ง ให้เข้ากับโทนที่มีอยู่ และอย่าแปลด้วยเครื่องสำหรับคำศัพท์ทางเทคนิคที่คุณไม่แน่ใจ

## การรายงานข้อบกพร่อง

เปิดประเด็นพร้อมรุ่นอุปกรณ์ของคุณ เวอร์ชัน Android และหากเกี่ยวกับการอ่านค่า ให้แนบ **การส่งออก** ที่แชร์
(ค่าที่บ่งบอกตัวตนของมันถูกปิดบัง) การส่งออกสร้างขึ้นเพื่อสิ่งนี้โดยเฉพาะ

## โค้ด

- บิลด์ release ไม่ใช่ debug ทดสอบบนอุปกรณ์จริง ดู[การสร้าง](BUILDING.md)
- เก็บความคิดเห็นออกจากโค้ด ชื่ออธิบายเจตนา เฮดเดอร์เดียวคือแบนเนอร์ใบอนุญาตที่ด้านบนของแต่ละไฟล์ซอร์ส
- ให้เข้ากับสไตล์ที่มีอยู่และทำให้การเปลี่ยนแปลงอยู่ในขอบเขต
