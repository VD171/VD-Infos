# VD Infos ユーザーガイド

VD Infos は **デバイスメソッドデバッガー** です。あらゆるデバイスの値を、それを読み取れる
あらゆるメソッドを通して読み取り、比較できるように読み取り結果を横に並べます。このガイドでは、
アプリのインストール、スキャンの実行、結果の読み方、レポートの共有を説明します。特定の個別の
結果を解釈して示すことはしません。比較を読むのは、あなた自身が自分のデバイス上で行うことです。

## 1. VD Infos とは

Android は、あなたがインストールするすべてのアプリに、デバイスの情報を数多く渡しています。
VD Infos は、ごく普通のアプリが何を読み取れるのかの一例を示します。そしてそれを *メソッド
デバッガー* として行います。すなわち、それぞれの情報について、それを読み取れる **あらゆる
メソッド** を通して値を読み取ります - プラットフォーム API、システムプロパティ、ネイティブ
呼び出し、システムマネージャー、コンテンツプロバイダー、ファイル、syscall、そしてハードウェア
キー証明 (TEE) - そしてそれらを並べて比較できるようにします。これはレンズで
あって、判定を下す機械ではありません。読み取り結果を提示し、それらを読むことはあなたに委ねます。

## 2. VD Infos ではないもの

- これはクリーナーでもブースターでも隠蔽ツールでも **ありません**。システム上の何も変更
  しません。読み取って比較するだけです。
- これは合否スコアでは **ありません**。生の読み取り結果を示します。それらがあなたの環境で何を
  意味するかは、あなた自身が自分のデバイス上で判断することです。
- インターネットを **必要としません**。ネットワークを遮断しても完全に動作します。

## 3. 動作要件

- Android 8.0 (API 26) 以降。
- 起動に特別な権限は不要です。対応する権限 (例えば使用状況へのアクセス) を付与した場合にのみ
  利用できる読み取りもあり、root 化されたデバイスでのみ存在する読み取りもあります。読み取りが
  利用できない場合、アプリは単にそれが利用できなかったことを示します。

## 4. インストールする APK

各リリースでは **2 つの APK** が公開されます。

- **SDK_35** - 厳格な現代のサンドボックスを対象とします。こちらを使ってください。
- **SDK_27** - 古い API レベルを対象とします。並べて比較する用途にのみ役立ち、ほとんどの
  人には必要ありません。

どちらも Android 8.0 以降でインストールできます。
[Releases](https://github.com/VD171/VD-Infos/releases) ページからダウンロードしてください。

## 5. インストールと初回起動

1. Releases から **SDK_35** APK をダウンロードし、インストールします (ブラウザやファイル
   マネージャーからのインストールを許可する必要があるかもしれません)。
2. アプリを開きます。アプリはそのままスキャン画面で開きます。アカウントもサインインもセット
   アップもありません。
3. 必要に応じて、アプリが尋ねる権限 (使用状況へのアクセスなど) を付与して、それに依存する
   読み取りを有効にします。これは完全に任意です。

## 6. スキャンの実行

スキャンのアクションをタップします。アプリはプローブを並列に展開し、結果が揃うたびにリストへ
ストリーミングし、進行状況をリアルタイムで表示します。スキャンは自動的に完了します。アプリが
開いている間だけ読み取り、バックグラウンドでは何も動かし続けず、放置されると自身を閉じます。

もう一度実行するには、再度スキャンします。各スキャンは前回の結果を置き換えます。

## 7. 結果の読み方

各項目はカードで、あらゆるレンズ (Java SDK メソッド、ネイティブメソッド、シェルなど) からの
読み取り結果を並べます。カードの色は、それらの読み取り結果が互いにどう関係しているかを一目で
示します。

- **一致** - すべてのレンズが一致しました。各メソッドが同じ値を返しました。
- **相違** - レンズが一致しませんでした。あるメソッドが他と異なる何かを返しました。
- **情報** - 判定の対象ではなく、参考として表示される読み取りです。
- **単独 / 利用不可** - 1 つのレンズだけが読み取れたか、どのレンズも読み取れませんでした。

カードは常に読み取り結果の全マトリクスを表示するので、どのレンズが何を言ったかを正確に確認
できます。折りたたまれたカードは最初の読み取りを表示します。展開するとすべてを表示します。

アプリが代わりに語るのはそこまでです。**ある相違があなたのデバイスで何を意味するか、そして
それについて何をすべきかは、あなたが調べることです** - それがデバッガーの本質です。証拠を
あなたの目の前に置き、それを読ませるのです。検索ボックスでプロパティや値で絞り込み、
フィルターチップでリストを狭めてください。

## 8. レポートのエクスポート

共有と保存のアクションは、画面上にあるものだけでなく **結果全体** を渡します。

- **JSON として共有 / 保存** - 機械可読な形式の完全なレポートで、アプリが内部で保持している
  のと同じデータです。保持したり、ツールに渡したりするための形式です。
- **テキストとして共有** - 相違点の、簡潔で人が読める要約です。

ID を含む値 (シリアル、IMEI、MAC アドレス、広告 ID など) は、公開スレッドに貼り付けたレポート
があなた自身の識別子を漏らさないように、**エクスポートされたレポートではマスクされます**。
判定と構造は保持されます。あなた (または root) だけが読めるデバイス上のコピーは、実際の値を
保持します。

## 9. AI エージェント向け

VD Infos は、人だけでなくツールに読まれるために作られています。各スキャンは完全なレポートを
アプリのプライベートストレージに書き込み、そのエクスポートは同じ機械可読な JSON です。デバイス
上で動作する AI コーディングアシスタントや分析スクリプトは、スクリーンショットを解析する代わりに、
1 つのコマンドで結果全体を読み取れます。専用の [AI エージェントガイド](AI-AGENTS.md) と
[エクスポート形式](EXPORT-FORMAT.md) のリファレンスを参照してください。

## 10. 言語とテーマ

アプリは、翻訳が存在する場合はシステム言語に従い、手動で選ぶこともできます。ダイナミック
カラーの Material 3 を使用し、ライト / ダークの設定に従います。

## 11. プライバシーの概要

すべてがデバイス上で動作します。読み取りはどこにも送信されず、レポートは明示的に共有または
保存したときだけデバイスを離れます。各スキャンは完全なレポートをアプリのプライベート
ストレージ (`files/last_snapshot.json`) に保持するのでツールが読めます。そのファイルは
アプリ自身または root だけが読め、次のスキャンが上書きし、デバイスを離れることはありません。
完全な説明は [プライバシー](PRIVACY.md) を参照してください。

## 12. よくある質問

**デバイス上の何かを変更しますか?** いいえ。読み取って比較するだけです。

**root が必要ですか?** いいえ。アプリは root なしで動作します。ごく一部の読み取りは root 化
されたデバイスでのみ存在し、プライベートなレポートファイルは root またはアプリ自身だけが読み
返せます。それ以外はすべて root なしで動作します。

**インターネットが必要ですか?** いいえ。完全にオフラインで動作します。よければネットワーク
アクセスを遮断してください。

**どの APK を使うべきですか?** SDK_35 です。SDK_27 ビルドは比較のためだけに存在します。

**なぜ一部の項目は利用不可と表示されるのですか?** そのメソッドがあなたのデバイスでその値を
読めなかったからです - 権限の欠如、サンドボックスのルール、または存在しないハードウェア。
それ自体が比較の一部です。

**問題の報告や検出対象の提案はどこで行えますか?**
[コントリビューション](CONTRIBUTING.md) を参照してください。ほとんどの検出リストはプレーン
テキストで、コードは不要です。
