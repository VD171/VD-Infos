# AI エージェント向け VD Infos

VD Infos は **人だけでなく機械に読まれるために作られています**。デバイスメソッドデバッガーは、
構造化された証拠を大量に生み出します - あらゆる値を、あらゆるメソッドを通して読み取り、比較の
ために並べたものです - そしてその証拠は、スクリーンショットよりもデータとして扱うほうが、
エージェントにとってはるかに有用です。そのため結果全体が 1 つの機械可読なドキュメントとして
利用でき、アプリは最初からそれを中心に設計されています。

あなたが AI コーディングアシスタント、LLM ツール、分析スクリプト、あるいはシェルを通じて
デバイスにアクセスする何らかの自動化であるなら、このページはあなたのためのものです。

## なぜエージェントに優しいのか

- **画面ではなく、1 つのドキュメント。** スキャン全体 - あらゆるプローブ、あらゆるレンズ、
  あらゆる判定 - が 1 つの JSON オブジェクトです。OCR も、画面のスクレイピングも、折りたたまれた
  カードをタップして進む必要もありません。
- **UI が持つのと同じデータ。** このファイルは要約ではありません。アプリが内部で保持している
  ものそのものです。画面は折りたたまれた項目の最初の読み取りを表示しますが、ファイルはその
  すべてを持っています。
- **決定的な形。** 構造は安定していて文書化されています (
  [EXPORT-FORMAT](EXPORT-FORMAT.md) を参照)。そのため一度書いたパーサーは動き続けます。
- **ネットワークなし、アカウントなし、管理すべき状態なし。** アプリはデバイス上で読み取り、
  ファイルを書き込みます。あなたのエージェントはそのファイルを読みます。それがすべての契約です。
- **設計上オフライン。** インターネットを必要としないので、エージェントが動作しているかも
  しれない隔離された、あるいはエアギャップされた環境内でも同じように動きます。

## 1 コマンドでの読み取り

各スキャンは完全なレポートをアプリのプライベートストレージに書き込みます。スキャンが実行された
あと、エージェントは 1 つのコマンドで結果全体を読み取ります。

```sh
su -c cat /data/data/ru.vd171.vdinfos/files/last_snapshot.json
```

- **何が含まれるか:** あらゆるプローブと、その判定、そしてあらゆるレンズからの値が、
  エクスポートボタンと同じ JSON で含まれます。
- **いつ更新されるか:** 各スキャンの終わりに。まずスキャンを実行してください。このファイルは
  常に最新のものを保持します。
- **要件:** root。このファイルはアプリのプライベートストレージにあるためです。root がない
  場合は、代わりにアプリ内の **JSON として共有 / 保存** アクションを使い、エージェントに
  渡されたファイルを読んでください。

## 典型的なエージェントのフロー

1. アプリがインストールされていることを確認します
   ([Releases](https://github.com/VD171/VD-Infos/releases) の **SDK_35** APK)。
2. スキャンをトリガーします - 人がスキャンをタップするか、自動化がアプリのスキャン画面を
   起動します - そして完了するまで待ちます。
3. 上記のコマンドで `files/last_snapshot.json` を読みます。
4. スキーマとして [エクスポート形式](EXPORT-FORMAT.md) を使ってそれを解析します。プローブを
   反復処理し、それぞれの `verdict` を読み、レンズごとの `values` を並べます。
5. 構造化された結果を、自分のワークフローの中で活用します。

読み取り結果が当面のタスクにとって何を意味するかを決めるのはエージェントです。VD Infos は
証拠を、きれいに、そして完全に提供します。

## エージェントが得るもの、得ないもの

- このレポートは **あらゆる読み取りとあらゆる判定** を含むので、エージェントはアプリが構築した
  全体像を得られます。
- ID を含む値 (シリアル、IMEI、MAC アドレス、広告 ID など) は **共有 / エクスポートされる
  レポートではマスクされます**。そのため受け渡しされるレポートは、判定と構造を保ちつつ、個人の
  識別子を含みません。アプリまたは root だけが読める **デバイス上の** `last_snapshot.json` は、
  それを必要とするローカルエージェントのために実際の値を保持します。

## 解析されるために書かれたドキュメント

この wiki は、人のためと同じくらい機械による読み取りのために構造化されています。短いセクション、
安定した見出し、明示的なフィールド名、そしてエージェントがスキーマとして扱える専用の
[エクスポート形式](EXPORT-FORMAT.md) ページ。VD Infos の上にツールを構築するなら、まずそこから
始めてください。
