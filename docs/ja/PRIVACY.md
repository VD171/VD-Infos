# プライバシー

プライバシーは VD Infos の一機能ではありません。それがすべての目的です。このページは、アプリ
があなたのデータに対して何をし、何をしないかを、あなたが検証できる平易な言葉で正確に述べます。

## 約束

- **すべてがデバイス上で動作します。** いかなる読み取りも、どのサーバーにも送信、アップロード、
  または伝送されません。アプリはインターネットを遮断しても完全に動作します。
- **アカウントなし、サインインなし、バックグラウンド作業なし。** アプリは開いている間だけ
  読み取り、バックグラウンドでは何も動かし続けず、放置されると自身を閉じます。
- **システム上の何も変更しません。** VD Infos は読み取って比較するだけです。デバイスの状態に
  書き込むことは決してありません。

## レポートはあなたの手元にとどまる

レポートは **あなたが明示的に共有または保存したときだけ** デバイスを離れます。それまでは、
いずれもデバイス上の 2 か所に存在します。

- **画面上**、アプリが開いている間。
- アプリの **プライベートストレージ** (`files/last_snapshot.json`) 内。これはアプリ自身または
  root だけが読めます。次のスキャンがそれを上書きし、デバイスを離れることはありません。これは
  ツールや AI エージェントが完全な結果を読めるように存在します。
  [AI エージェントガイド](AI-AGENTS.md) を参照してください。

## エクスポートはマスクされる

レポートを共有または保存するとき、ID を含む値 - シリアル、IMEI、MAC アドレス、広告 ID など -
は、公開スレッドに貼り付けたレポートがあなた自身の識別子を漏らさないように、レポートが書き
込まれる前に **マスクされます**。判定と構造は保持されます。墨消しされるのは機微な値だけです。
デバイス上のプライベートなコピーは、あなた自身の用途のために実際の値を保持します。

## 権限

アプリは権限を必要とせずに起動します。対応する権限 (例えば使用状況へのアクセス) を付与した
場合にのみ利用できる読み取りもあり、それを付与するかどうかは完全にあなたの選択です。読み取り
が利用できない場合、アプリは単にそう示します。

## 自分で検証する

これらのどれも、信用して受け取る必要はありません。

- ソースは公開されています: <https://github.com/VD171/VD-Infos>。
- マニフェストはソースの中にあります。どの権限を宣言しているか確認してください。
- ファイアウォールでアプリのネットワークアクセスを遮断するか、インターネットをオフにしても、
  同じように動作し続けます。

レポートの読み方とエクスポートに含まれる内容については、[ユーザーガイド](USER-GUIDE.md) を
参照してください。
