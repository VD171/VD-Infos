# 行動規範

## 私たちの誓い

私たちはメンバー、コントリビューター、メンテナーとして、年齢、体格、目に見えるまたは見えない
障害、民族、性的特徴、性自認と性表現、経験の度合い、教育、社会経済的地位、国籍、容姿、人種、
宗教、性的指向に関わらず、すべての人にとって VD Infos コミュニティへの参加がハラスメントのない
体験であるようにすることを誓います。

## 私たちの基準

前向きな環境に寄与する振る舞いの例:

- 異なる意見、視点、経験を尊重すること。
- 建設的なフィードバックを与え、また快く受け入れること。
- コミュニティにとって最善のことに集中すること。
- 他の人々に共感を示すこと。

容認できない振る舞いの例:

- 荒らし、侮辱的または軽蔑的なコメント、そして個人的または政治的な攻撃。
- 公的または私的なハラスメント。
- 明示的な許可なく他人の私的な情報を公開すること。
- 専門的な場で不適切と合理的にみなされうるその他の行為。

## 執行

虐待的、ハラスメント的、またはその他の容認できない振る舞いの事例は、メンテナー
**vd.priv8@pm.me** に報告できます。すべての苦情は迅速かつ公正に審査され、調査されます。
メンテナーは、あらゆる事案の報告者のプライバシーと安全を尊重する義務を負います。

## 帰属

この行動規範は [Contributor Covenant](https://www.contributor-covenant.org) バージョン 2.1
を基に作成されています。
