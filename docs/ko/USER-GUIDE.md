# VD Infos 사용자 안내서

VD Infos는 **기기 메서드 디버거** 입니다. 모든 기기 값을, 그것을 읽을 수 있는 모든 메서드를
통해 읽고, 비교할 수 있도록 읽은 값을 나란히 늘어놓습니다. 이 안내서는 앱 설치, 스캔 실행,
결과 읽기, 보고서 공유를 다룹니다. 특정한 개별 결과를 대신 해석해 주지는 않습니다. 비교를
읽는 일은, 당신 자신이 당신의 기기에서 할 몫입니다.

## 1. VD Infos란 무엇인가

Android는 당신이 설치하는 모든 앱에게 기기의 정보를 많이 넘겨줍니다. VD Infos는 아주 평범한
앱이 무엇을 읽을 수 있는지 그 예를 보여 주며, 그것을 *메서드 디버거* 로서 수행합니다. 즉,
각 정보 조각에 대해 그것을 읽을 수 있는 **모든 메서드** 를 통해 값을 읽습니다 - `Build.*`,
`SystemProperties`, `getprop`, 네이티브 `__system_property_get`, 시스템 매니저, 콘텐츠
프로바이더, 파일, syscall, 그리고 하드웨어 키 증명 (TEE) - 그리고 그것들을 나란히 늘어놓아
비교할 수 있게 합니다. 이것은 렌즈이지, 판정을 내리는 기계가 아닙니다. 읽은 값을 드러내고,
그것을 읽는 일은 당신에게 맡깁니다.

## 2. VD Infos가 아닌 것

- 이것은 청소 도구도, 부스터도, 숨김 도구도 **아닙니다**. 시스템의 아무것도 바꾸지 않습니다.
  읽고 비교할 뿐입니다.
- 이것은 합격/불합격 점수가 **아닙니다**. 가공하지 않은 읽은 값을 보여 줍니다. 그것이 당신의
  환경에서 무엇을 의미하는지는, 당신 자신이 당신의 기기에서 판단할 몫입니다.
- 인터넷이 **필요하지 않습니다**. 네트워크를 차단해도 완전하게 동작합니다.

## 3. 요구 사항

- Android 8.0 (API 26) 이상.
- 시작하는 데 특별한 권한은 필요하지 않습니다. 해당 권한 (예를 들어 사용 정보 접근) 을
  부여해야만 사용할 수 있게 되는 읽기도 있고, 루팅된 기기에서만 존재하는 읽기도 있습니다.
  읽기를 사용할 수 없는 경우, 앱은 단순히 사용할 수 없었다고 표시합니다.

## 4. 설치할 APK

각 릴리스는 **두 개의 APK** 를 공개합니다.

- **SDK_35** - 엄격한 현대 샌드박스를 대상으로 합니다. 이것을 사용하세요.
- **SDK_27** - 더 느슨한 SELinux 도메인을 가진, 더 오래된 API 레벨을 대상으로 합니다. 나란히
  비교하는 용도로만 유용합니다. 대부분의 사람에게는 필요하지 않습니다.

둘 다 Android 8.0 이상에서 설치됩니다.
[Releases](https://github.com/VD171/VD-Infos/releases) 페이지에서 내려받으세요.

## 5. 설치와 첫 실행

1. Releases에서 **SDK_35** APK를 내려받아 설치합니다 (브라우저나 파일 관리자로부터의 설치를
   허용해야 할 수도 있습니다).
2. 앱을 엽니다. 앱은 곧바로 스캔 화면으로 열립니다. 계정도, 로그인도, 설정도 없습니다.
3. 필요하다면 앱이 묻는 권한 (사용 정보 접근 등) 을 부여해 그에 의존하는 읽기를 활성화합니다.
   이는 전적으로 선택 사항입니다.

## 6. 스캔 실행

스캔 동작을 누릅니다. 앱은 프로브를 병렬로 펼쳐 내보내고, 결과가 도착할 때마다 목록으로
스트리밍하며, 진행 상태를 실시간으로 표시합니다. 스캔은 스스로 완료됩니다. 앱이 열려 있는
동안에만 읽고, 백그라운드에서는 아무것도 계속 돌리지 않으며, 방치되면 스스로 닫힙니다.

다시 실행하려면 다시 스캔하세요. 각 스캔은 이전 결과를 대체합니다.

## 7. 결과 읽기

각 항목은 카드로, 모든 렌즈 (Java SDK 메서드, 네이티브 메서드, 셸 등) 에서 읽은 값을
늘어놓습니다. 카드의 색은 그 읽은 값들이 서로 어떻게 관련되는지를 한눈에 알려 줍니다.

- **일치** - 모든 렌즈가 일치했습니다. 메서드들이 같은 값을 반환했습니다.
- **상이** - 렌즈들이 일치하지 않았습니다. 어떤 메서드가 다른 것들과 다른 무언가를 반환
  했습니다.
- **정보** - 판정의 대상이 아니라 참고용으로 표시되는 읽기입니다.
- **단독 / 사용 불가** - 렌즈 하나만 읽을 수 있었거나, 어느 것도 읽을 수 없었습니다.

카드는 언제나 읽은 값의 전체 행렬을 보여 주므로, 어느 렌즈가 무엇을 말했는지 정확히 볼 수
있습니다. 접힌 카드는 첫 번째 읽은 값을 보여 줍니다. 펼치면 전부 보입니다.

앱이 당신을 대신해 말해 주는 것은 거기까지입니다. **어떤 상이가 당신의 기기에서 무엇을
의미하는지, 그리고 그에 대해 무엇을 해야 하는지는 당신이 조사할 몫입니다** - 그것이 디버거의
본질입니다. 증거를 당신 앞에 놓고, 그것을 읽게 하는 것이지요. 검색 상자로 속성이나 값으로
걸러 내고, 필터 칩으로 목록을 좁히세요.

## 8. 보고서 내보내기

공유와 저장 동작은 화면에 있는 것뿐 아니라 **결과 전체** 를 건네줍니다.

- **JSON으로 공유 / 저장** - 기계가 읽을 수 있는 형식의 완전한 보고서로, 앱이 내부에 담고 있는
  것과 같은 데이터입니다. 보관하거나 도구에 넘길 형식입니다.
- **텍스트로 공유** - 상이점을, 사람이 읽을 수 있게 간결히 요약한 것입니다.

신원을 담은 값 (일련번호, IMEI, MAC 주소, 광고 ID 등) 은 공개 스레드에 붙여 넣은 보고서가
당신 자신의 식별자를 새어 나가게 하지 않도록 **내보낸 보고서에서는 가려집니다**. 판정과 구조는
보존됩니다. 당신 (또는 루트) 만 읽을 수 있는 기기 내 사본은 실제 값을 유지합니다.

## 9. AI 에이전트를 위하여

VD Infos는 사람뿐 아니라 도구가 읽도록 만들어졌습니다. 각 스캔은 완전한 보고서를 앱의 비공개
저장소에 기록하고, 그 내보내기는 같은 기계 판독 가능 JSON입니다. 기기에서 동작하는 AI 코딩
어시스턴트나 분석 스크립트는 스크린샷을 파싱하는 대신 단 하나의 명령으로 결과 전체를 읽을 수
있습니다. 전용 [AI 에이전트 안내서](AI-AGENTS.md) 와 [내보내기 형식](EXPORT-FORMAT.md) 참조
문서를 보세요.

## 10. 언어와 테마

앱은 번역이 존재하는 경우 시스템 언어를 따르며, 직접 고를 수도 있습니다. 다이내믹 컬러를 쓰는
Material 3을 사용하고, 밝게 / 어둡게 설정을 따릅니다.

## 11. 한눈에 보는 프라이버시

모든 것이 기기에서 동작합니다. 어떤 읽은 값도 어디로도 전송되지 않으며, 보고서는 당신이
명시적으로 공유하거나 저장할 때만 기기를 떠납니다. 각 스캔은 완전한 보고서를 앱의 비공개
저장소 (`files/last_snapshot.json`) 에 보관하므로 도구가 읽을 수 있습니다. 그 파일은 앱 자신
또는 루트만 읽을 수 있고, 다음 스캔이 덮어쓰며, 기기를 떠나지 않습니다. 전체 설명은
[프라이버시](PRIVACY.md) 를 보세요.

## 12. 자주 묻는 질문

**내 기기의 무언가를 바꾸나요?** 아니요. 읽고 비교할 뿐입니다.

**루트가 필요한가요?** 아니요. 앱은 루트 없이 동작합니다. 극히 일부 읽기만 루팅된 기기에서
존재하고, 비공개 보고서 파일은 루트나 앱 자신만 읽어 들일 수 있습니다. 그 외 모든 것은 루트
없이 동작합니다.

**인터넷이 필요한가요?** 아니요. 완전히 오프라인으로 동작합니다. 원한다면 네트워크 접근을
차단하세요.

**어떤 APK를 써야 하나요?** SDK_35입니다. SDK_27 빌드는 비교를 위해서만 존재합니다.

**왜 일부 항목은 사용 불가라고 나오나요?** 그 메서드가 당신의 기기에서 그 값을 읽을 수 없었기
때문입니다 - 권한 누락, 샌드박스 규칙, 또는 존재하지 않는 하드웨어. 그것 자체가 비교의
일부입니다.

**문제를 신고하거나 탐지 대상을 제안하려면 어디로 가야 하나요?**
[기여하기](CONTRIBUTING.md) 를 보세요. 대부분의 탐지 목록은 평문 텍스트이며 코드가 필요
없습니다.
